# TimeCraft — Luxury Watch E-Commerce Store

**TimeCraft** is a modern, responsive e-commerce web application designed for a premium luxury watch brand. Built with core web technologies, it features dynamic shopping cart interactions, multi-page product navigation, and Google OAuth 2.0 authentication.

---

## 🚀 Live Demo

Check out the live deployment here:  
👉 **https://malateshpn.github.io/TimeCraft/**

----

## Features

- **Luxury UI/UX Design:** Dark-themed, elegant interface tailored for premium watch collections.
- **Responsive Layout:** Fully optimized across desktop, tablet, and mobile browsers using CSS Flexbox & Grid.
- **Multi-Page Navigation:** Complete user journeys spanning index, shop, product details, account, cart, contact, and authentication pages.
- **Interactive Shopping Cart:** Dynamic item management with state persistence using browser LocalStorage.
- **Google OAuth Integration:** Instant login options alongside standard user registration and authentication workflows.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Authentication:** Google OAuth 2.0 API
- **Version Control & CI/CD:** Git, GitHub
- **Deployment:** GitHub Pages
